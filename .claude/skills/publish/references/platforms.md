# Platform caption rules

| | LinkedIn | Instagram Reel | TikTok | YouTube Short |
|---|---|---|---|---|
| Visible before "more" | ~210 chars | ~125 chars | ~100 chars | Title only |
| Ideal length | 900–1,500 chars | 150–400 chars | 100–300 chars | Title ≤60 chars; description 1–3 lines |
| Hook | Line 1 stands alone, no emoji | Line 1 repeats the on-screen hook | Hook in caption *and* in `tiktokData.title` | Title = the hook, as a claim or question |
| Body | Short paragraphs, white space, one idea | 2–4 lines, one takeaway | One line + question | Who it's for + link to full video/podcast |
| Hashtags | 3–5 at end | 3–6 at end | 3–5, one broad + niche | 2–3 in description; `#Shorts` optional |
| CTA | Question to drive comments | "Save this" / "Send to a leader who…" | Question or "Follow for part 2" | "Subscribe for the full series" |
| Links | First comment | First comment; "link in bio" | Bio only | Description is fine |
| Tone | Most formal; full argument | Concise, visual | Most conversational | Searchable: use terms people type |

Default hashtag pool: #BusinessTransformation #AITransformation #DigitalTransformation #Leadership #Strategy #FutureOfWork #TalentParadox #UKBusiness

Video specs: 9:16, 1080×1920, ≤90s for Reels, ≤3 min for TikTok/Shorts as a safe default. LinkedIn accepts 9:16 but 1:1 shows larger in desktop feeds.
